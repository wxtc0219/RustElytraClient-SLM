# SlimefunHelper（SLM）甲飞参数说明

本包带了两套参数，二选一导入即可（**推荐 A**，A 就是本整合包实测跑起来的那套，甲飞的全部参数都在 A 里；B 是给习惯用 `.nbt` 快照的人的一份参考）：

| 方式 | 内容 | 位置 |
| --- | --- | --- |
| **A. 运行时配置（推荐，实测可用）** | 13 个 `*.yml`，包含甲飞/简易控制/烟花/安全全部参数 | `slimefunhelper/runtime/` → `.minecraft/slimefunhelper/runtime/` |
| **B. 3c3u 存档快照** | 单个 `.nbt`，从 3c3u 那台机器导出的 SLM 配置快照 | `slimefunhelper/config/slm-3c3u甲飞推荐参数.nbt` → `.minecraft/slimefunhelper/config/`，游戏内 `!!config load slm-3c3u甲飞推荐参数.nbt` |

> ⚠️ SlimefunHelper **1.1.7.2 的配置目录是 `slimefunhelper/runtime/`**（旧版才是 `config/sfhelper-configs/`）。放错位置不会生效。

---

## 核心甲飞参数（本包 A 方案里已经设好的值）

### 1. 鞘翅甲飞 `elytra.armor-fly`（最关键）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `enable` | **true** | 开启鞘翅甲飞 |
| `enable-hotkey` | **Z** | 开关热键（可改） |
| `armor-mode` | **TICK** | 换甲时机：TICK = 每次移动都切换（最快对齐服务器） |
| `force-no-elytra` | **true** | **起飞时强制切甲** —— 不开会一直穿鞘翅飞、掉耐久，必须开 |
| `max-delay-ticks` | **7** | 飞行状态同步延后刻数 |
| `armor-fly-fix-grim-bad-packets-1` | **true** | Grim 反作弊 BadPackets 修复 |
| `pose-fix` | **true** | 修正碰撞箱/眼睛高度 |
| `render-fix` | **true** | 渲染修复（看起来像在飞） |
| `anti-kick` | **true** | 飞行防踢出 |
| `enable-liquid-fly` | false | 水体飞行（不需要） |
| `enable-manually-swap` | false | 允许手动切甲暂停 |

### 2. 简易鞘翅控制 `elytra.simple-flight-control`

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `enable-control` | **true** | 开启简易鞘翅控制 |
| `enable-control-hotkey` | **Z** | 热键（和甲飞同一个键，一起开关） |
| `flight-mode` | **CONTROL** | 控制模式（不是 CREATIVE） |
| `motion-mode` | **FIRE_WORKS** | 动力源：烟花动力（发包动力 = VOID，可试） |
| `motion-lerp-argument` | **1.0** | 转向平滑参数（<1 更平滑，1.0 = 直接应用 WASD） |
| `horizontal-no-gravity` | **true** | 水平飞行尽量不掉高 |
| `use-floating-utils` | **true** | 悬停优化（悬停不耗烟花） |
| `pause-when-accelerate` | **true** | 加速时暂停控制（减少和烟花推进打架） |
| `firework-rotation-last-ticks` | **3** | 烟花末段额外转头刻数 |
| `auto-fly` | **false** | 自动飞行（自动从地面起飞/无输入保持飞行；卡住自救可以开） |
| `auto-fly-auto-jump-off` | false | 自动起跳 |

### 3. 烟花 `elytra.custom-fireworks`

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `firework-auto-use-vanilla` | **true** | 智能无缝续烟花 |
| `firework-delay-multiply-vanilla` | **40** | 原版烟花内置冷却 = 该值 ×（飞行时间+1）刻 |
| `fireworks-lag-delay` | **true** | 烟花延迟（防卡） |
| `motion-amount` | 1.7 | 动量大小 |
| `firework-speed-limit-up/down` | 5.0 | 速度上限（可控速） |

### 4. 安全/回弹 `move-safety`

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `log-resync-packets` | false | 打开可打印服务器位置修正（排查用） |
| `check-setback-packets` | true/false | 反作弊回弹检测（打开会打印 `[AC] 反作弊回弹!`） |
| `grimac-1-21-2-input-features` | false | 1.21.2+ Grim 输入检测（1.21.1 服务器一般不用开） |

## 怎么改（三种方式）

1. **直接改文件**：改 `.minecraft/slimefunhelper/runtime/mov.yml` 里的值，游戏内 `!!config reload`
2. **游戏内命令**：`!!config set mov elytra.armor-fly.force-no-elytra true` 然后 `!!config reload`
3. **GUI**：`!!config open` 打开配置文件界面逐项改

## 验证是否生效

- 游戏内按 **Z**，聊天栏应出现：`[+] 鞘翅甲飞`、`[+] 简易鞘翅控制`
- 再按一次出现 `[-]` 表示关闭
- 如果没有反应，检查：SH 版本是否为 1.1.7.2、`runtime/mov.yml` 是否在正确目录

## 另外：REC 自己的参数不在 SH 里

- `RSTConfig.json`（`.minecraft/config/`）：`FoodIndex`（4 = 熟猪排）、`elytraFireworkSpeed`（1.2）、`netherSeed` 等
- `baritone/settings.txt`：`slimePhysics false` 是 MagicBaritone 专属，必须有
