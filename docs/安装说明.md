# 安装说明（v1.0.0）

组合：**RustElytraClient（SLM 甲飞接管扩展版）+ MagicBaritone + SlimefunHelper** —— 自动飞向坐标、自动补给烟花，**穿护甲飞、不穿鞘翅、不掉耐久**。

## 0. 需要的 4 个 jar

| 文件 | 从哪拿 |
| --- | --- |
| `RustElytraClient-1.21.1-beta1.6-slm-takeover-1.0.0.jar` | 本仓库 `release/` |
| `MagicBaritone-1.0.0-mc1.21.1-fabric.jar` | [`deps/README.md`](deps/README.md) |
| `SlimefunHelper-1.21.1-1.1.7.2.jar` | [`deps/README.md`](deps/README.md)（认 1.21.1 构建）|
| `fabric-api-0.116.17+1.21.1.jar` | [`deps/README.md`](deps/README.md) |

环境：Minecraft **1.21.1**、Fabric Loader ≥ 0.16、Java **21**。

## 1. 装

1. 关游戏。
2. 删掉 mods 里的 `baritone-api-*.jar`、`baritone-helper-*.jar`（原生 baritone 和 MagicBaritone 不能共存），原来的 `RustElytraClient-*.jar` 也移走。
3. 上面 4 个 jar 丢进 `.minecraft/mods/`。
4. 复制配置（文件夹没有就新建）：

```
config/RSTConfig.json       → .minecraft/config/RSTConfig.json
baritone/settings.txt       → .minecraft/baritone/settings.txt   （UTF-8 无 BOM）
slimefunhelper/runtime/*.yml → .minecraft/slimefunhelper/runtime/  （13 个）
```

5. 进游戏，模组列表里确认是 **MagicBaritone**、**slimefunhelper**、**rust-elytra-client**。

## 2. 用

- `Z` 开 SH 的「鞘翅甲飞 + 简易鞘翅控制」
- `]` 开 REC 界面，填目的地 X / Z
- 点第 4 个按钮 **「开始飞行(SLM甲飞接管)」**，然后挂机

## 3. 起飞前备货

| 物资 | 要求 |
| --- | --- |
| 烟花火箭 | 1664 个（26 组） |
| 熟猪排 | 30 个以上（`FoodIndex: 4`，不够会中止） |
| 鞘翅 | 背包里有 1 个即可（不用穿） |
| 胸甲 / 图腾 | 快捷栏、副手放好 |
| 末影箱 | 快捷栏带末影箱，里面的潜影盒装烟花和食物 |

补给是自动开末影箱取潜影盒里的东西。

## 4. 参数（别人飞不起来基本都卡在这）

仓库里 `slimefunhelper/runtime/`（13 个 yml）和 `baritone/settings.txt` 就是调好的参数，**照抄**，别自己调：

| 在哪 | 参数 | 值 |
| --- | --- | --- |
| `slimefunhelper/runtime/mov.yml` → `elytra.armor-fly` | `enable` / `enable-hotkey` / `armor-mode` / `force-no-elytra` | `true` / `hotkey:Z` / `TICK` / `true` |
| 同上 → `elytra.simple-flight-control` | `enable-control` / `motion-mode` | `true` / `FIRE_WORKS` |
| `baritone/settings.txt` | `slimePhysics` | `false`（MagicBaritone 独有，原生 baritone 会报错；**UTF-8 无 BOM**）|
| `config/RSTConfig.json` | `FoodIndex` / `isAutoLog` / `elytraFireworkSpeed` | `4` / `true` / `1.2` |

- 飞不起来先看：有没有按 `Z` 开甲飞、mods 里是不是 MagicBaritone（不是 Baritone）、`slimePhysics false` 那一行加没加。
- 各人所处服务器的甲飞设置可能不同；本组合的参数是在 **3c3u** 上调的，换服可能需要自己微调。
- 每一项参数是干什么的、怎么改、怎么验证，见 [`参数说明.md`](参数说明.md)。

## 5. 出问题

- `[AC] 反作弊回弹!`：服务器行为，压不下去。
- `无可用熟猪排!` / 补给失败：物资不够，任务会中止并自动退出。
- 别用原生 baritone，会冲突；上游新版已移除 baritone，本扩展只适用于 beta1.6。
- 日志看 `.minecraft/logs/latest.log`，搜 `第0段补给任务开始`、`所需补给:`、`所需的潜影盒槽位列表`。
