# SLM 甲飞自动飞行 — 安装说明（v1.0.0，支持 1.21.1 / 1.21.4 / 1.21.11）

> 组合：**RustElytraClient（SLM 甲飞接管补丁版） + MagicBaritone + SlimefunHelper**
>
> 效果：自动飞向目标坐标，自动补给烟花，**穿护甲飞、不穿鞘翅、不掉鞘翅耐久**。

---

## 1. 环境要求

| 项 | 1.21.1 | 1.21.4 | 1.21.11 |
| --- | --- | --- | --- |
| MC 版本 | **1.21.1** | **1.21.4** | **1.21.11** |
| Fabric Loader | 0.16+（实测 0.20.1） | 0.16+ | 0.18+ |
| Java | 21 | 21 | 21 |
| 内存 | ≥4 GB | ≥4 GB | ≥4 GB |
| 服务器 | 支持甲飞（3c3u 实测） | 支持甲飞 | 支持甲飞 |

## 2. 选文件（按你的 MC 版本）

| 组件 | 1.21.1 | 1.21.4 | 1.21.11 |
| --- | --- | --- | --- |
| REC 补丁 | `release/RustElytraClient-1.21.1-beta1.6-slm-takeover-1.0.0.jar` | `release/RustElytraClient-1.21.4-beta1.6-slm-takeover-1.0.0.jar` | `release/RustElytraClient-1.21.11-beta1.6-slm-takeover-1.0.0.jar` |
| MagicBaritone | `deps/MagicBaritone-1.0.0-mc1.21.1-fabric.jar` | `deps/MagicBaritone-1.0.0-mc1.21.4-fabric.jar` | `deps/MagicBaritone-1.0.0-mc1.21.11-fabric.jar` |
| SlimefunHelper | `deps/SlimefunHelper-1.21.1-1.1.7.2.jar` | `deps/SlimefunHelper-1.21.4-1.1.7.1.jar` | `deps/SlimefunHelper-1.21.11-1.1.7.2.jar`（或 1.2.1.3） |
| Fabric API | `deps/fabric-api-0.116.17+1.21.1.jar` | `deps/fabric-api-0.110.0+1.21.4.jar` | `deps/fabric-api-0.140.0+1.21.11.jar` |

**每个 MC 版本只需 4 个 jar，放进 `.minecraft/mods/` 即可。**

## 3. 安装步骤

1. 关闭游戏。
2. 按上表把 **4 个 jar** 放进 `.minecraft/mods/`（三个版本的 jar 不要混放）。
3. **确认 mods 里没有原生 baritone**：删除 `baritone-api-*.jar`、`baritone-helper-*.jar`、
   `baritone-meteor-*.jar`（MagicBaritone 就是 baritone，二者不可共存）。
   如果原来有 `RustElytraClient-*.jar`（任何版本）也一并移走。
4. 复制配置（**没有文件夹就新建**）：
   - `config/RSTConfig.json` → `.minecraft/config/RSTConfig.json`
   - `baritone/settings.txt` → `.minecraft/baritone/settings.txt`（关键：含 `slimePhysics false`）
   - `slimefunhelper/runtime/*.yml` → `.minecraft/slimefunhelper/runtime/`

   或者用推荐参数快照：
   - `slimefunhelper/config/MagicBaritone-推荐参数.nbt` → `.minecraft/slimefunhelper/config/`，
     进游戏后执行 `!!config load MagicBaritone-推荐参数.nbt`

   > 甲飞关键参数逐项说明见 **`史莱姆参数说明.md`**。
5. 启动游戏，确认模组列表：**MagicBaritone**（不是 Baritone）+ **SlimefunHelper** + **rust-elytra-client**。

## 4. 使用

1. 按 **Z** 打开「鞘翅甲飞 + 简易鞘翅控制」（SlimefunHelper）
2. 按 **`]`** 打开 RST 菜单，填目的地 X / Z
3. 点第 **4** 个按钮「**开始飞行(SLM甲飞接管)**」

起飞后保持挂机即可，任务会按段飞行、每段自动检查补给。

## 5. 物资准备（重要）

REC 的补给是自动开**末影箱**取潜影盒里的物资，请确认：

| 物资 | 要求 |
| --- | --- |
| 烟花火箭 | 目标量 **1664 个**（26 组）；少于这个数会触发补给 |
| 食物 | **30 个以上熟猪排**（`FoodIndex: 4` = 熟猪排）；末影箱里也没有时只警告并继续 |
| 鞘翅 | **背包里有至少 1 个**（甲飞要求背包存在鞘翅，但不穿戴） |
| 胸甲 | 放在快捷栏（甲飞会自动换甲） |
| 图腾 | 副手/快捷栏放图腾（防摔死） |
| 末影箱 | 快捷栏要有末影箱；末影箱里的潜影盒装烟花/食物 |

## 6. 热键 / 参数（已调好，一般不用改）

| 配置 | 位置 | 值 |
| --- | --- | --- |
| 甲飞 + 简易控制热键 | `slimefunhelper/runtime/mov.yml` | `Z` |
| 甲飞模式 | `.minecraft/slimefunhelper/runtime/elytra.yml` | `armor-mode: TICK` |
| 起飞强制切甲 | 同上 | `force-no-elytra: true`（关键：不然会穿鞘翅飞、掉耐久） |
| 动力源 | 同上 | `motion-mode: FIRE_WORKS` |
| 打开菜单键 | 游戏内 | `]` |
| 自动退出 | `config/RSTConfig.json` | `isAutoLog: true` |

## 7. 已知问题

1. **反作弊回弹**：Grim 服务器上飞行中会周期出现 `[AC] 反作弊回弹!`，轻微顿挫，属服务器行为。
2. **1.21.11 版没有轨迹预览渲染**（只影响可视轨迹线）。
3. 任务失败会触发 REC 原版自动退出；退出瞬间 REC 自身存在 NPE 崩溃老 bug（与本补丁无关）。
4. 原生 baritone 与本组合冲突，必须删除。
5. 上游 RustElytraClient 新版（1.21.11 官方版）已移除 baritone；本补丁 1.21.11 版是把
   beta1.6 的 1.21.8 分支源码移植过去的，不是官方新版。

## 8. 出问题看日志

`.minecraft/logs/latest.log` 搜索：

- `第0段补给任务开始` → 补给阶段是否进入
- `所需补给:` → 计算出的需求（正常应有值）
- `所需的潜影盒槽位列表` → 是否找到潜影盒
- `无可用` / `物资不足` → 物资问题
- `[RSTAutoLog]` → 自动退出原因
