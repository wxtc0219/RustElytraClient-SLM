## 二、静态检查（三版本均通过）

### 1. REC → baritone 类/成员链接检查

用 `javap` 扫描 REC jar 的全部 class，提取所有 `baritone/*` 引用：

- 引用的 **10 个 baritone 类** 在对应 MagicBaritone jar 中全部存在
- 引用的 **25 个 baritone 方法/字段** 全部可解析（其中 `isActive` 继承自 `IBaritoneProcess`，已确认存在）

### 2. REC mixin 目标检查

- 1.21.1 / 1.21.4：`RustElytraClient-refmap.json` 中 7 条 mixin 引用全部能在
  yarn → intermediary 映射中找到（2 条是父类方法 `Screen.init` / `Entity.tick`，按继承算有效）
- 1.21.11：mixin 注解已被 loom 直接重映射为 intermediary，
  6 条目标类+方法全部能在 1.21.11 映射中找到
- baritone 相关 mixin 目标（`baritone.behavior.LookBehavior`、
  `baritone.command.defaults.ExecutionControlCommands`）在 **未混淆** MagicBaritone 中存在，
  且 `ExecutionControlCommands` 构造器里 mixin 需要的 `boolean[]` 局部变量存在

### 3. MagicBaritone mixin refmap 检查

- MB 1.21.4：46 条 refmap 条目全部可在 1.21.4 映射中找到（16 条为继承方法）
- MB 1.21.11：42 条 refmap 条目全部可在 1.21.11 映射中找到
- 两个 jar 的 `fabric.mod.json` 的 `minecraft` 依赖分别为 `1.21.4` / `1.21.11`

### 4. 第 4 模式补丁完整性（三版本逐项核对）

`TaskType.SLM_TAKEOVER`、`isSlm()`、菜单第 4 按钮、补给/槽位 switch 分支、
补给鞘翅前置检查放宽、SLM 起飞逻辑、容器标题宽松匹配、等待容器 120 tick、
挖补给盒 30s + 手挖兜底、食物不足只警告、HUD 状态文案 —— 全部存在。

## 三、已知未覆盖点

1. 1.21.4 / 1.21.11 **没有在游戏内实际跑过任务**（只做了静态检查）
2. 1.21.11 的轨迹预览渲染停用（新渲染 API 改动）
3. 1.21.4 / 1.21.11 的 MagicBaritone 为本分支移植版，行为未必 100% 等价官方 1.21.1 版
4. 反作弊回弹、REC 原版任务失败自动退出+NPE 等老问题不在本补丁修复范围内
